# Earth visual sources

`earth-night-nasa.jpg`: NASA Earth Observatory, Black Marble 2016 color map,
3600 × 1800. NASA Earth Observatory images by Joshua Stevens, using Suomi NPP
VIIRS data from Miguel Román, NASA GSFC.

Source and credit: https://science.nasa.gov/earth/earth-observatory/earth-at-night/maps/
Original asset: https://assets.science.nasa.gov/content/dam/science/esd/eo/images/imagerecords/144000/144898/BlackMarble_2016_01deg.jpg

The file is stored unmodified. The website wraps it onto a tilted sphere and adds
atmospheric lighting in its renderer. It is a decorative historical composite,
not live satellite imagery.
